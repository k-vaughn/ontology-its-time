# The Time Ontology for ITS (bundle)

![Draft for review only](https://isotc204.org/assets/img/draft_for_review.svg)

This ontology imports the concepts from the various Time Ontology for ITS patterns and bundles them into a single ontology.

The The Time Ontology for ITS (bundle) consists of the following patterns:

- [Core](classes/CorePattern.md)
- [Fuzzy Time](classes/FuzzyTimePattern.md)
- [Schedule](classes/SchedulePattern.md)

The formal definition of this ontology is available in [TURTLE Syntax](its-time.ttl).
