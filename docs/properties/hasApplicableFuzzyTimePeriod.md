# hasApplicableFuzzyTimePeriod

Named fuzzy time *periods* from a code list (e.g. seasons, tidal states, peak hours) that qualify applicability together with other period rules. Multiple values indicate several such periods apply at once, as when a source standard encodes a set of flags (e.g. ISO 14823-1 GDD `FuzzyTime`). For a point in time relative to a named event and offset, use :FuzzyTimeInstant and :FuzzyTimeCode instead.
